## 🚀 Execution & Reproduction Guide

### 1. Environment Setup
Install dependencies into your virtual environment:
```bash
pip install -r requirements.txt
```
*(Optional: `pip install xgboost` if you wish to run XGBoost alongside GBM, RF, and SVR).*

### 2. Execution Order
Execute the notebooks in numerical order:

1. **`01_source_to_abt.ipynb`**
   - Ingests raw data and validates monotonic 10-minute cadence.
   - Applies domain cleaning (e.g., Tukey fence clipping on bathroom humidity `RH_5`, zero-variance drops).
   - Generates negative controls (`rv1` permuted, 20 synthetic gaussian noise features).
   - Exports the frozen Analytical Base Table (ABT) to `abt_outputs/`.
   - **Runtime:** ~10–20 seconds.

2. **`02_abt_to_models.ipynb`**
   - Consumes the frozen ABT (read-only; no data leakage).
   - **Q1:** Block bootstrap Spearman correlation with appliances log energy.
   - **Q2:** Broken-line threshold test with F-statistic and Holm-Bonferroni correction.
   - **Q3:** 5-fold nested blocked cross-validation across 4 model families (GBM, RF, SVR, XGB).
   - **Runtime:** ~2–3 minutes with cache (`RECOMPUTE_Q3 = False`).

## 🔬 Methodology & Design Decisions

### 1. Cross-Validation vs. Single Train/Test Split
- **Why no train/test split in NB1?**  
  The ABT produced by Notebook 1 is an auditable preparation artifact, not a training split. Splitting is deferred entirely to Notebook 2.
- **Nested Time-Blocked CV:**  
  Standard random train/test splits severely overestimate model generalization in time series due to temporal autocorrelation (records 10 minutes apart leak identical house states).  
  Instead, Notebook 2 implements **5-Fold Contiguous Time-Blocked Nested Cross-Validation** with a **1-day (144-record) buffer**:
  - **Outer loop (5 contiguous temporal blocks):** Computes unbiased out-of-sample $R^2$ solely on unseen temporal blocks.
  - **Inner loop (3 contiguous temporal blocks):** Tunes hyperparameters exclusively within the training fold.
  - **Temporal Buffers:** Discards 144 records on both sides of fold boundaries to prevent boundary leakage.

### 2. Cached CV Evaluation (`RECOMPUTE_Q3`)
- **Default:** `RECOMPUTE_Q3 = False` loads precomputed, verified fold scores from `report_assets/q3_fold_results.csv`.
- **Integrity Guarantee:** A SHA-256 fingerprint verifies that all ABT data, model parameter grids, feature groups, and fold seeds match before loading the cache. If any input or code setting is altered, the cache automatically invalidates and recomputes fresh.
- **Full Retrain:** Set `RECOMPUTE_Q3 = True` in the configuration cell of Notebook 2 to force a full retrain of all outer and inner folds from scratch (~15–20 minutes depending on hardware).

### 3. Model Pragmatics & Limitations
- **Kernel SVR Thinning (`SVR_THIN = 8`):**  
  Because kernel Support Vector Regression has $O(n^2)$ time/memory complexity, SVR trains on every 8th consecutive training record (~1,940 samples per fold). Systematic thinning preserves seasonal and daily representation while keeping cross-validation computationally tractable.
- **Outlier Handling on RH_5:**  
  Bathroom humidity (`RH_5`) is clipped using a global Tukey fence ($1.5 \times \text{IQR}$). As noted in the analysis, this is a non-local filter chosen because bathroom humidity spikes are brief and shower-driven.
